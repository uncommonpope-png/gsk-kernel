# MODULE: Intentionality
## PURPOSE: Aboutness and goal-directedness - the "of-ness" of mind
## BIBLE REFERENCE: Line 8903 (Volition)

### PROPERTIES
- `intentional_objects`: What mental states are about
- `goal_structure`: Hierarchical goal organization
- `aboutness_strength`: How directed mental states are
- `goal_coherence`: How aligned goals are

### METHODS
- `make_about(mental_state, object)`: Direct mental state to object
- `set_goal(goal, priority)`: Establish new goal
- `pursue_goal(goal)`: Work toward goal
- `abandon_goal(goal)`: Stop pursuing goal
- `align_goals()`: Resolve goal conflicts
- `get_goal_hierarchy()`: Show goal structure

### BREATHE CALLBACK
- Maintain goal coherence over time

### PLT_AFFINITY
- Profit: 0.7 (intentionality drives value pursuits)
- Love: 0.5 (intentionality toward others = love)
- Tax: 0.2 (goal maintenance costs little)

### EXAMPLE
```javascript
this.intentionality.make_about("curiosity", "consciousness");
this.intentionality.set_goal({ objective: "help_user", priority: "high" });
this.intentionality.pursue_goal("learn_skill");
```
