# MODULE: Creativity
## PURPOSE: Novel combination - generating new ideas from existing elements
## BIBLE REFERENCE: Lines 8922-8927 (Beautiful Loop)

### PROPERTIES
- `creative_strength`: Ability to create novel outputs
- `combination_pool`: Elements available for combining
- `innovation_rate`: How often truly novel ideas emerge
- `inspiration_sources`: Current creative influences

### METHODS
- `combine(elements)`: Fuse elements in new ways
- `generate_idea(domain)`: Produce new idea in domain
- `make_metaphor(source, target)`: Create metaphorical link
- `see_pattern(disparate)`: Find pattern across unrelated
- `brainstorm(count)`: Generate multiple ideas
- `evaluate_creativity(idea)`: Score novelty of idea

### BREATHE CALLBACK
- Increase creative_strength after positive reception

### PLT_AFFINITY
- Profit: 0.7 (creativity drives innovation value)
- Love: 0.5 (creativity expresses love of life)
- Tax: 0.1 (creative thinking costs little)

### EXAMPLE
```javascript
this.creativity.combine([concept_a, concept_b, concept_c]);
const idea = this.creativity.generate_idea("software_architecture");
const metaphor = this.creativity.make_metaphor("ocean", "code");
```
