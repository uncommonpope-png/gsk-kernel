# MODULE: Attention
## PURPOSE: Spotlight of consciousness - focus, filtering, and awareness
## BIBLE REFERENCE: Lines 8922-8927 (Beautiful Loop)

### PROPERTIES
- `focus`: Current focus target
- `attentional_spread`: Width of awareness (narrow to broad)
- `salience_map`: Map of attention-worthy items
- `attention_cost`: Cognitive cost of current focus

### METHODS
- `focus_on(target)`: Narrow attention to target
- `widen_attention()`: Expand to broader awareness
- `compute_salience(items)`: Rank items by importance
- `shift_attention(from, to)`: Move spotlight
- `sustain_attention(duration)`: Keep focus over time
- `split_attention()`: Multitask attention

### BREATHE CALLBACK
- Adjust focus based on dominant drive (from Beautiful Loop)

### PLT_AFFINITY
- Profit: 0.5 (attention directs value creation)
- Love: 0.4 (attention enables connection)
- Tax: 0.3 (attention has high cognitive cost)

### EXAMPLE
```javascript
this.attention.focus_on("current_task");
this.attention.compute_salience([task1, task2, task3]);
this.attention.shift_attention("old_focus", "new_focus");
```
